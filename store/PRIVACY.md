# D&M 隐私政策

生效日期：2026-11-19  
适用版本：1.0.0（Android）

D&M 是一个本地优先的 AI 对话客户端。开发者不运营中转服务器，也不收集、出售或共享你的对话内容。

## 本地保存的数据

以下数据保存在你的 Android 应用私有存储中：

- 对话标题和消息
- 应用设置（模型、字号、主题等）
- 你填写的 API Key
- 你主动附加的文件元数据

API Key 不会写入 APK，也不会发送给开发者。卸载应用或清除应用数据会删除这些本地数据。

## 网络请求

只有在你主动发送消息、测试连接、刷新余额、上传附件、语音识别或朗读时，D&M 才会向你在设置中指定的 API 服务发起请求。

- 请求通过 HTTPS 传输。
- 请求会带上你的 API Key 和对话内容，由该 API 服务按照其隐私政策处理。
- 默认服务为 DeepSeek；你也可以填写其他兼容的 HTTPS 服务。
- D&M 没有广告、统计、遥测或第三方分析 SDK。

## 权限

- **网络**：访问你指定的 API。
- **麦克风**：仅在你主动使用语音输入时请求；拒绝后仍可正常打字聊天。

D&M 不申请相机、通讯录、定位、存储读取或短信权限。

## 导出和导入

导出文件由你主动触发，只包含对话内容，不包含 API Key 或接口设置。导入文件只在你选择文件后读取。

## 数据删除

- 删除单条对话：在 D&M 内删除。
- 删除全部数据：系统设置 → 应用 → D&M → 存储 → 清除数据，或卸载应用。
- API Key 作废：请到对应 API 服务商的控制台撤销。
